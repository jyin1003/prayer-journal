# Prayer Journal

## Getting Started
1. Activate virtual environment
    ```
    # WINDOWS
    python -m venv .venv
    .\.venv\Scripts\Activate.ps1

    # LINUX
    python -m venv .venv
    source .venv/bin/activate
    ```

2. Install dependencies
    ```
    npm init -y
    npm install
    ```

3. Start the app
    ```
    npm run dev
    ```

## Setup Backend
1. Create a Supabase project
2. Paste your Supabase URL and public API key into the `.env` file
